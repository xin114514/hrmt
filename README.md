钢4改名mod制作工具（HOI4 Rename Mod Tool）

readme是拿豆包瞎写的，大伙看个乐就行。

一款可视化的《钢铁雄心 4》（Hearts of Iron IV）本地化改名 MOD 制作工具，支持批量修改国家 / 人物名称，自动扫描原版本地化文件，生成可直接使用的 MOD 文件。
功能特性
- 📁 自动识别 HOI4 原版安装目录，无需手动查找文件
- 🌐 支持多语言本地化（简体中文、英文、法语、德语、俄语等 9 种语言）
- 📜 自动扫描并解析：
  - 国家标签及对应意识形态名称
  - 人物角色名称及所属国家 / 意识形态
- ✏️ 可视化表格编辑，支持快速筛选、双击编辑新名称
- 💾 项目存档功能，可保存编辑进度，支持后续修改和重新生成
- 🚀 一键生成完整 MOD 文件，包含本地化替换文件和 descriptor 配置
运行环境
- Windows 7/10/11
- Python 3.8+
- 依赖：tkinter（Python 内置，一般无需额外安装）
快速开始
方式 1：直接运行（源码）
1. 确保已安装 Python 3.8+
2. 下载hoi4_rename_mod_tool.py文件
3. 双击运行或在终端执行：
python hoi4_rename_mod_tool.py
方式 2：打包成 EXE（可选）
如需无 Python 环境运行，可使用 pyinstaller 打包：
pip install pyinstaller
pyinstaller -F -w -i icon.ico hoi4_rename_mod_tool.py
（icon.ico为可选图标文件，无则省略）
使用教程
1. 创建项目
1. 打开工具后，进入「项目面板」
2. 填写基本信息：
  - 项目名称：用于存档文件命名
  - MOD 名称：生成的 MOD 在游戏中显示的名称
  - 语言：选择要修改的本地化语言（默认简体中文）
  - 原版目录：工具会自动检测，也可手动选择 HOI4 安装目录（需包含 hoi4.exe）
  - MOD 输出目录：默认我的文档\Paradox Interactive\Hearts of Iron IV\mod
3. 点击「创建项目并进入工作台」
2. 扫描原版数据
1. 在工作台点击「扫描 / 合并原版」按钮
2. 工具会自动解析原版本地化文件，加载所有国家 / 人物名称数据
3. 扫描完成后，表格会显示所有可修改的本地化 key、对应国家 / 人物信息
3. 编辑新名称
1. 在表格中找到需要修改的条目，双击「新人物 (国家）名」列
2. 输入自定义名称，按 Enter 保存或点击其他位置自动保存
3. 可使用「过滤」框快速查找目标条目（支持模糊搜索）
4. 保存项目（可选）
- 点击「存档」保存当前编辑进度（自动使用首次保存的路径）
- 点击「另存为」可将项目保存为.hoi4rename.json文件，方便后续编辑
5. 生成 MOD
1. 确认至少填写了一个新名称后，点击「一键生成 MOD」
2. 工具会自动在指定输出目录生成完整的 MOD 文件夹和配置文件
3. 生成完成后，在 HOI4 启动器中启用该 MOD 即可生效
6. 打开已有项目
- 在项目面板或工作台点击「打开项目存档」
- 选择已保存的.hoi4rename.json文件，可继续编辑之前的项目
注意事项
1. 原版目录必须包含：hoi4.exe、common文件夹、localisation文件夹
2. 生成的 MOD 会覆盖对应本地化 key 的名称，不会修改原版文件
3. 建议在生成 MOD 前先保存项目，防止编辑内容丢失
4. 支持的本地化 key 格式：字母、数字、下划线、点、冒号、短横线
5. MOD 输出目录建议使用默认路径，否则需手动将 MOD 文件夹复制到 HOI4 的 mod 目录
常见问题
Q1: 扫描失败 / 找不到原版目录？
A1: 手动选择 HOI4 安装目录，确认路径下有hoi4.exe、common、localisation文件夹。Steam 版默认路径：
- C:\Program Files (x86)\Steam\steamapps\common\Hearts of Iron IV
- D:\SteamLibrary\steamapps\common\Hearts of Iron IV
Q2: 生成的 MOD 在游戏中不生效？
A2:
1. 确认在 HOI4 启动器中启用了该 MOD
2. 检查 MOD 输出目录是否正确（默认我的文档\Paradox Interactive\Hearts of Iron IV\mod）
3. 确认选择的语言与游戏内设置的语言一致
Q3: 表格中部分条目显示为 key 而非名称？
A3: 该 key 在所选语言的本地化文件中无对应翻译，工具会显示原始 key 或历史名称，不影响修改。
Q4: 编辑后如何重新扫描并保留已修改内容？
A4: 直接点击「扫描 / 合并原版」，工具会自动保留已填写的新名称，同时更新其他数据。
